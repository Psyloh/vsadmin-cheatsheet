# vsadmin-cheatsheet
Public participative most used/useful commands list

To participate with VSCode (no addon)
- create a GitHub account
- fork this repository
- create a local directory
- Open it with VSCode's terminal
- clone your forked repository : git clone https://github.com/{your-name}/{your-repository-name} .
- change things
- stage changes
- commit
- create a pull request on GitHub
